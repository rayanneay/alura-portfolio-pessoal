# Portfólio Pessoal

Este repositório reúne o desenvolvimento de um portfólio pessoal, desenvolvido durante a trilha **HTML e CSS para Projetos Web** da Alura.

O projeto foi construído para praticar a criação e organização de páginas web, aplicando estrutura semântica em HTML, estilização com CSS e adaptação da interface para diferentes tamanhos de tela.

## Tecnologias utilizadas

- HTML5
- CSS3
- CSS Flexbox
- Media queries

## Conteúdos aplicados

- Estruturação de páginas com tags HTML semânticas;
- Organização do conteúdo em arquivos HTML;
- Estilização de cabeçalhos, rodapés e demais elementos com CSS;
- Criação de layouts com CSS Flexbox;
- Uso das unidades `rem`, `px` e porcentagens;
- Uso de `:root` e variáveis CSS com `var()`;
- Responsividade para diferentes tamanhos de tela;
- Linkagem de fontes externas;
- Noções de ferramentas de layout, como Figma, e publicação de projetos no GitHub.

## Cursos da trilha

Este projeto acompanha os conteúdos dos seguintes cursos:

1. **HTML e CSS: ambientes de desenvolvimento, estrutura de arquivos e tags**
2. **Aprenda HTML, CSS e boas práticas de desenvolvimento**
3. **Organize sua página e deixe-a responsiva para diferentes telas**

## Objetivo

Desenvolver uma base prática em HTML e CSS por meio da construção de um portfólio pessoal, aplicando boas práticas de organização, estilização e responsividade.
